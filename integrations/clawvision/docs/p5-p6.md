# P5–P6 闭环（0.6.0）

## 插件治理补齐

- 每个插件声明 `version`、`apiVersion`、`dependencies`、`isolation`。
- Registry 拒绝重复 ID、不兼容 API 和缺失的必需依赖。
- `PluginErrorBoundary` 隔离单个插件渲染失败并提供重试。
- 第三方插件只能通过 `registerSandboxed()` 注册，在无 `allow-same-origin` 的 iframe 中执行。
- VisualizationSpec 在服务端版本化保存，可生成公开 share token。

## P5 通用数据可视化

- 服务端导入 CSV、JSON；Parquet 通过可选 `pyarrow` 适配。
- 自动识别 number/string/boolean/datetime 和 nullable。
- 折线、柱状、散点、热力图、箱线图插件。
- 图表类型、X/Y 字段和标题配置。
- 点击图形标记产生共享筛选，所有图表联动。
- 原生拖拽重排 Dashboard。
- 导出 PNG、SVG、CSV。
- 保存和恢复包含 Dashboard、Dataset snapshot、筛选的 VisualizationSpec。

## P6 3D 实验与模型可视化

- GLB、GLTF、OBJ、STL 以版本化模型资产上传。
- `core.cad-model-3d`：格式加载、节点树、材质、颜色、灯光、Before/After 叠加。
- `core.embedding-evolution-3d`：训练 step 时间轴、播放与初始状态叠加。
- `core.simulation-replay-3d`：点云、轨迹、向量场和仿真状态回放。
- 三个插件独立实现，没有共享单体 model factory。

## API

- `POST/GET /api/datasets`
- `GET /api/datasets/:id`
- `POST/GET /api/visualization-specs`
- `GET /api/visualization-specs/:id`
- `GET /api/shared/:token`
- `POST/GET /api/model-assets`
- `GET /api/model-assets/:id`
