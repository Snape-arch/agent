# P4 插件化可视化架构（0.4.0）

## 协议

插件协议位于 `src/visualizations/types.ts`：

```ts
interface VisualizationPlugin<T = unknown> {
  id: string;
  supportedArtifactTypes: string[];
  canRender(input: ArtifactSchema): boolean;
  createDefaultSpec(input: ArtifactSchema): VisualizationSpec;
  render(props: RendererProps<T>): React.ReactNode;
}
```

`PluginHost` 只依赖协议和 Registry。Registry 使用 `import.meta.glob('./plugins/*.tsx', { eager: true })` 自动发现插件，因此新增插件不需要修改 Registry、Run 页面或工作台核心代码。

## 首批插件

- `core.time-series`：时间序列折线图
- `core.table`：通用表格
- `core.image-grid`：图片/预测样本网格
- `core.confusion-matrix`：混淆矩阵
- `core.scatter-2d`：二维散点图
- `core.embedding-3d`：3D embedding
- `core.json-viewer`：JSON 查看器
- `core.log-terminal`：日志终端

## 新增插件

只需在 `src/visualizations/plugins/` 新建一个默认导出 `VisualizationPlugin` 的 `.tsx` 文件。上传的 Artifact 会通过 `type`、`mimeType` 和 `canRender` 自动匹配；无需修改 `App.tsx`。

运行架构验收：

```bash
pnpm verify:plugins
pnpm build
```
