# ClawVision 0.14.0 · P0–P2 closure

## P0 · reproducible release

- CI uses Node 22.23.1, pnpm 11.9.0 and `pnpm install --frozen-lockfile`.
- API, web, PostgreSQL, MinIO and MinIO Client images use immutable version tags rather than `latest`.
- `docker compose up -d --wait` is validated by `scripts/container_smoke.py` against PostgreSQL and S3-compatible storage.
- `scripts/release_check.py` validates clean install, v1→v7 upgrade and migration idempotency.
- `scripts/acceptance_p0.py` executes 20 Agent plus 20 Text-to-3D flows and asserts no active workers remain.
- `scripts/backup_restore.sh backup|restore` covers PostgreSQL and MinIO data.

## P1 · experiment and 3D fusion

- A Run can bind input, baseline, checkpoint, overlay, output or simulation model assets at a training step.
- `/api/runs/:id/timeline` aligns metrics, artifacts and 3D assets by step.
- Parameter Lab comparison automatically includes the integrated 3D timeline for baseline and generated Runs.
- The Python SDK reports embedding evolution, point clouds, trajectories, vector fields and simulation frames, and links model checkpoints.
- The shared slider drives metrics, spatial artifacts and before/after model overlays.

## P2 · asset production workbench

- Projects, folders, stages, tags and search filters.
- Raw/Edit/LOD/Release workflow, archive/restore and release approval.
- Independent mesh/material/texture component versions.
- Multi-select batch project/stage/tag updates.
- Version lineage, metadata diff summary and Run/Scene/generation reference inspection.
- Reference-protected soft delete followed by grace-period garbage collection.

## Local validation note

The current Windows host has no Docker CLI. Compose configuration and scripts are committed, while the GitHub Actions Linux Compose job is the authoritative real-container gate. Backend, migration, plugin, TypeScript and browser checks run locally.
