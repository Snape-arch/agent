# P0–P1 发布与网格内核闭环 · 0.13.0

## P0 · 发布与运行闭环

- `.github/workflows/ci.yml` 是统一发布门：24 项 API/后端测试、数据库升级、插件架构、TypeScript 与生产构建。
- `scripts/release_check.py` 在临时数据库上验证全新安装、v1 旧库升级到 v6，以及重复启动的幂等性。
- `docker-compose.yml` 编排 Nginx Web、Python API、PostgreSQL 17 与 MinIO；API 和数据库均配置健康检查。
- glTF 多文件输入支持一次选择 `.gltf + .bin + textures`，文件编码在 Web Worker 中完成，不阻塞主 UI。
- 大型修改器通过 `model_operation_jobs` 后台执行；取消发生在资产落盘前，服务重启会把中断任务标记失败，源 Scene 不变。

## P1 · 本地生产网格内核

- GLB、嵌入式/外部资源 GLTF、OBJ 与二进制/ASCII STL 进入统一的 glTF Scene Graph。
- OBJ/STL 原件保留为 Raw 资产，编辑源转换为自包含 GLB，版本血缘记录原始格式和资产 ID。
- Boolean 不再使用 cutter AABB 裁面：两个真实三角网格会转换为体素占用，执行 Union/Subtract/Intersect，再重建封闭表面。
- 体素接触正则化消除边/角接触形成的非流形边；自动化测试要求 Boolean 输出 boundary/non-manifold edge 均为零。
- Decimate 使用顶点聚类并删除退化/重复三角形；Remesh、Normal Repair、Bevel/Chamfer 重建法线并为缺失数据生成 UV。
- 修改器仍从不可变 Raw 资产按栈重放，可启停、排序、删除和恢复。

### 精度边界

当前 Boolean 是稳定、封闭且确定性的体素 Mesh 内核，适合实验资产、语义网格和 Web 编辑。它不是精确 NURBS/B-Rep CAD 求解器；毫米级制造公差、解析曲面和 STEP/IGES 拓扑应在后续接入 OpenCascade/Manifold 专业 Worker。
