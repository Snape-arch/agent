# ClawVision 0.16 · P0–P3 closure

## P0 release baseline

- Server/package release truth is 0.16.0 and database upgrades are migrations 9–10.
- Production verification includes backend integration tests, plugin boundary verification and the Vite production build.
- Authentication remains opt-in (`CLAWVISION_AUTH_MODE=enabled`) so an existing single-user install upgrades without lockout.

## P1 real training

Parameter Lab supports `simulator`, `local-python`, and `local-conda`. The process providers use a JSONL protocol for metrics, logs, artifacts and final results. Tasks persist in `training_jobs` and support bounded concurrency, timeout, cancellation and failure status. Set `CLAWVISION_TRAINING_CONDA_ENV=fepf` (default) to use the local CUDA environment.

## P2 geometry kernels

Run `scripts/local-worker-env.ps1`, then configure:

```powershell
$env:GEOMETRY_MANIFOLD_COMMAND='conda run --no-capture-output -n clawvision-geometry python workers/manifold_worker.py'
$env:GEOMETRY_OPENCASCADE_COMMAND='conda run --no-capture-output -n clawvision-geometry python workers/opencascade_worker.py'
```

Manifold handles watertight mesh repair/boolean/decimation. CadQuery/OpenCascade handles STEP/IGES tessellation plus B-Rep fillet/chamfer. Managed geometry remains available through the existing HTTPS provider contract.

## P3 access control

Migration 10 adds tenants, users, memberships, roles, hashed API tokens, quotas, audit logs and encrypted-credential reference storage. Enable auth, bootstrap once through `POST /api/auth/bootstrap`, then send `Authorization: Bearer <token>`. Roles are viewer, researcher, admin and owner; destructive purge and token issuance require admin.
