# ClawVision 0.17 · P0–P2 闭环

## P0 · 多租户与访问控制

- Run、任务、Dataset、Visualization Spec、3D 资产、Studio、训练和几何资源均带租户边界。
- 对象存储键使用租户前缀；跨租户读取返回 404，跨租户引用或覆盖返回 403。
- 首次初始化、登录、短期会话 Token、可撤销 API Token、成员角色和审计日志已接入 UI 与 API。
- 租户配额覆盖 Run 数、共享任务并发和存储字节；API Key 仅通过服务端环境变量或加密凭据引用解析。

## P1 · 持久任务与生产运行

- 数据库任务队列具备幂等键、优先级、租约、心跳、重试、死信、取消和过期租约回收。
- API 可使用嵌入式 Worker，也可通过 `CLAWVISION_EMBEDDED_WORKERS=false` 与独立 Worker 分离部署。
- PostgreSQL + MinIO Compose 同时部署 API 和 Worker；迁移 v11–v13 支持旧库升级。
- `/api/metrics` 输出 Prometheus 指标，请求日志包含 request ID；任务和配额可从工作区设置查看。
- `scripts/standalone_worker_check.py` 黑盒验证 API 提交任务后由独立 Worker 完成且不残留租约。

## P2 · 通用训练接入

- Python SDK 支持 Bearer Token、离线批量补传、训练血缘、Checkpoint 和父 Run/恢复关系。
- 提供框架原生基类兼容的 Lightning、Hugging Face Trainer、Keras 回调，以及框架无关回调。
- rank 0 单写、world size/rank count、代码引用、数据集引用和运行环境被持久化。
- 本地 Python 与 Conda/CUDA Worker 使用 JSONL 流式协议，上报指标、日志、Checkpoint、Artifact 和 GPU 遥测。
- 训练任务支持取消、超时、重启续跑和持久任务重试。

## 发布验收

```bash
pnpm test:release
python scripts/standalone_worker_check.py
docker compose up --build --wait
python scripts/container_smoke.py
```

本机 RTX 5060 / Conda `fepf` 冒烟已验证 CUDA 训练、指标、Checkpoint 与 GPU
利用率、显存、温度、吞吐遥测协议。第三方 Text-to-3D 与在线 LLM 仍需各自有效的服务端凭据，
不属于本轮 P0–P2 训练闭环的运行依赖。
