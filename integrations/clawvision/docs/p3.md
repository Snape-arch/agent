# P3 Parameter Lab（0.3.0）

## 已闭环能力

- Schema 驱动参数控件：类型、范围、单位、默认值、校验、依赖关系。
- 历史 Run 锁定为 Baseline，展示 Before / After 参数差异。
- 单次实验、单参数 Sweep、二维网格搜索。
- 参数快照保存、恢复与恢复默认值。
- 作业队列、1–3 并发限制、预计时长和成本提示。
- 创建计划后由后端生成真实 Run，持续写入指标、事件和结果 Artifact。
- 创建成功后自动进入 Baseline / 新 Run 对比视图。

## 基础设施

- 数据库：SQLite 默认；设置 `DATABASE_URL=postgresql://...` 切换 PostgreSQL。
- Artifact：本地对象目录默认；设置 `ARTIFACT_STORE=s3` 切换 S3/MinIO。
- SDK：批量上报 `/api/runs/:id/batch`，网络失败写入本地 JSONL，`sync_offline()` 顺序补传。
- 队列：`POST /api/jobs` 创建计划，`GET /api/jobs` 查询进度。

可选生产适配器依赖见 `requirements-optional.txt`，配置见 `.env.example`。

## 当前边界

- Parameter Job 当前使用内置确定性训练执行器，已经是真实的服务端队列、Run 与持久化链路，但还不是 PyTorch/Kubernetes 外部训练器。
- PostgreSQL 和 S3/MinIO 已提供适配代码与配置，当前环境未连接真实外部实例做集成测试。
- 成本/时长为启发式预估；生产版需接入 GPU 规格、历史吞吐和云计费数据。
- 队列为单进程执行器；服务重启后的作业恢复、分布式调度与多租户配额属于下一阶段。
