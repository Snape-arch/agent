# P0–P3 0.19 发布闭环

## P0 · 后端边界

- 生产入口改为 `uvicorn asgi:app`。ASGI 适配层负责生命周期、流式响应和旧路由兼容桥接；新领域逻辑通过无传输依赖的 `CollectionService`、`DatasetService` 承载。
- API 错误统一为 Problem Details 结构，包含 `type`、`title`、`status`、`code`、`error`、`detail` 与 `requestId`。
- 所有持久化集合接口支持有界 `page` / `pageSize`，并返回稳定的 `pagination` 元数据。

## P1 · 浏览器、并发与故障

- Playwright 覆盖实验比较、数据 Dashboard、3D 工作台和 AI 3D Studio 真实生成链路，并保存数据与 3D 视觉基线。
- `concurrent_sdk_benchmark.py` 验证多线程 Run 创建、批量指标上报、完成和断线落盘状态。
- `soak_test.py` 默认运行 60 分钟；传入 `--url` 时直接验证 PostgreSQL/MinIO Compose 栈，结束后逐 Run 校验完成状态并检查残留任务。
- 定时 CI 在真实 Compose 栈执行 PostgreSQL/MinIO 停止、恢复、健康探测、并发上报和 60 分钟 soak。没有 Docker 的开发机只运行隔离 SQLite 短时同路径冒烟。

## P2 · 列式数据与 ML 生态

- CSV、JSON 与原始 Parquet 数据统一保存规范 JSON 预览和 Parquet 列式副本；S3/MinIO 与本地对象存储均支持原子二进制读写。
- DuckDB Provider 对 Parquet 执行字段投影、过滤、分组、聚合、排序和分页下推；缺少可选依赖时保持原 JSON 查询引擎兼容。
- 独立 Python 3.12 夹具验证 TensorBoard Event、Lightning Callback、Transformers TrainerCallback 与 Keras Callback 的真实包继承关系。

## P3 · 3D 质量与包体

- Chrome 基线截图覆盖真实 CAD 装配体和 embedding 画面；测试同时断言 WebGL 可用、几何体存在、无 context loss 且资源预算通过。
- `threeBudget` 采集帧耗时、JS heap、geometry、texture、draw call、triangle 和 WebGL context 指标。
- OBJ CAD 往返检查使用包围盒、尺寸、表面积、体积和面数公差。
- Three.js core、controls、loaders、geometries 与其余 addons 深度拆包；发布门禁限制首屏、Three core 和 addon chunk 的体积。
