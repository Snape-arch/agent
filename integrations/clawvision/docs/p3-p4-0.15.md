# ClawVision 0.15.0 · P3–P4 closure

## P3 semantic edit Agent

`POST /api/model-scenes/:id/agent-runs` creates a non-destructive run. The service records structure understanding, planned operations, affected nodes, risk, cost, expected duration, quality decisions, repair cycles, and the preview artifact. High/critical risk pauses at `awaiting-confirmation`. A run that reaches `ready` still has not modified the source; `POST /api/scene-agent-runs/:id/apply` performs an optimistic version check and atomically creates the new scene/asset version.

The UI exposes this lifecycle in the semantic scene editor. Reject, cancel, Quality failure, timeout, and stale-version conflict all preserve the source scene.

## P4 professional geometry Worker

`GET /api/geometry/providers` reports capabilities and configuration for:

- `builtin-voxel`: fast local preview and fallback mesh operations.
- `manifold`: command adapter for robust mesh Boolean/repair/remesh/UV work.
- `opencascade`: command adapter for exact B-Rep Boolean, fillet, chamfer, STEP and IGES.
- `external`: HTTPS job API for managed geometry services.

Scene jobs first create a low-resolution preview asset. Professional results pass the quality gate before the scene is changed, then replace the preview with a new immutable Release asset. Command Workers support progress, durable checkpoints, timeout, and process termination on cancel; HTTP Workers use POST/GET/DELETE `/jobs` and may resume from a checkpoint key.

### Command Worker protocol

The Worker reads one JSON object from stdin and emits JSON lines:

```json
{"type":"checkpoint","progress":55,"stage":"brep","checkpoint":{"solidId":"..."}}
{"type":"result","format":"glb","content":"<base64>","stats":{"kernel":"OpenCascade"}}
```

Set `GEOMETRY_MANIFOLD_COMMAND` or `GEOMETRY_OPENCASCADE_COMMAND` on the API service. Secrets and external service credentials remain server-side.

## Format boundary

ASCII PLY meshes and point clouds are canonicalized locally. Binary PLY, STEP and IGES remain Raw assets and require a configured professional Provider for tessellation or conversion. This preserves an explicit distinction between approximate mesh editing and exact CAD operations.
