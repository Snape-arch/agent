# P0–P3 closure · 0.11.0

## P0 · Managed API production path

- Meshy native two-stage preview/refine adapter; PBR refine output is downloaded as GLB.
- Tripo native asynchronous text-to-model adapter as fallback.
- Local implicit preview remains available and is produced before the high-quality asset.
- Managed providers bypass local GPU memory checks; command providers retain GPU concurrency and memory budgets.
- Keys are server-side environment variables. Base URLs must be HTTPS, except localhost for contract tests.
- Provider downloads are limited to 128 MB and must use HTTPS or localhost.

## P1 · 3D quality system

- Preview, raw provider asset and release GLB are stored as separate model assets.
- OBJ checks: degenerate faces, boundary edges, non-manifold edges and disconnected components.
- GLB checks: binary envelope, mesh primitives, position/normal/UV accessors, materials and textures.
- OBJ output automatically returns through welding, duplicate/degenerate removal, normal repair, UV generation and PBR packaging.
- The release quality report and all asset IDs are attached to job stats; a release below the configured threshold is rejected while preview/raw assets remain available for diagnosis.

## P2 · Non-destructive editor

- Scene Graph selection supports multiple nodes, grouping, duplicate and delete.
- Transform Gizmo and numeric position editor support World/Local space and snapping.
- CSG operation and evaluation order can be edited without flattening the plan.
- Remesh/repair are stored as modifiers rather than destructively replacing the source node.
- UI history supports undo/redo; confirmed operations are persisted in `studio_scene_versions` migration v4.

## P3 · Natural-language 3D editing

- Chinese/English commands cover move, rotate, scale, material/color, CSG, duplicate, delete, remesh and repair.
- Commands produce structured operations, affected node IDs, an explanation and a preview plan.
- Preview highlights affected nodes. Confirm creates a server-side scene version; cancel changes nothing.

## Verification

- 20 Python unit/integration tests.
- 20 consecutive Agent + Text-to-3D acceptance flows with zero active workers afterward.
- TypeScript project build and Vite production build.
- Managed API contract tests use local Meshy/Tripo protocol simulators; no paid provider call is made without a user-owned API key.
