    新建自进化 Run

    候选效果待验证，参数变化本身不代表质量提升。

    真实质量信号
    运行与发布阶段
    门禁细节
    冻结任务与成对回放
    检索与工具路由支持内置回放。搜索集选择候选，每个预声明任务类别的留出集至少需要 30 个任务组；回放支持暂停和检查点恢复。已使用的留出题禁止跨实验重用，回放不计入线上影子或灰度证据。
    任务文件格式与边界
    字段：target_type、target_key、baseline_payload、cases、documents。每个 case 必须有唯一 id、group_id、query、reviewed_by；检索还需 expected_source_refs，对应 documents 的 source_ref、title、content。工具路由需 route.allowed_tools、required_tools、forbidden_tools。同一资料或任务的变体应使用同一个 group_id；segment 可声明任务类别，省略时为 default。各类别样本不足或退步会阻止提名。origin 为 task 时须引用已存在的 task_id，问题从任务记录冻结。标签是审核者提供的期望，系统尚未验证语义或标注者身份。
    文件上限 8MiB、500 个用例、100 个资料快照。内置检索不加载向量或重排模型，路由不执行工具。提示词、报告模板只提供候选，语义验收需要真实模型输出与独立审核。
    等待审核后的真实任务集；没有数据时不会宣称已经进化。
    模型输出与独立盲评
    捕获主模型的成对回答 → 授权会话用户独立盲评 → 分歧由另一位会话用户裁决 → 按任务类别验收。
    真实模型回答
    仅通过当前配置的主模型生成答案，不执行工具。按全部留出题成对调用；中断后保留已保存回答，继续时必须使用同一模型与参数。
    先选择实验并核对预算。token 上限不代表费用估算。
    评审与裁决授权
    选择已通过协作邀请加入的会话用户。评审者与裁决者分开授权，角色不能互换；组织者需另行核验真人身份和专业资格。
    评审页复用加入协作时的登录会话。原始判断与裁决永久保留。
    文件格式与评审边界
    模型输出文件需 definition_digest、report_digest、outputs。每题包含 case_id、input_digest、variants.control 与 variants.candidate；每个答案含 text、provider、model、policy_digest。必须覆盖选定实验全部留出题；上传前从实验的下载证据核对绑定。
    评分文件含 packet_digest、reviewer、ratings。每项含 entry_id、options.A 与 options.B；每个评分含 text_digest、score（0..1）、rationale、critical_error（布尔）。评分不可覆盖；大于 0.25 的审核分歧或严重错误阻止报告评分通过。
    外部导入仅记录自报名称和模型来源。内置捕获保存应用调用凭据；在线评审绑定服务端会话及实验角色。持有原始资料的所有者仍可能识别答案，真人独立性与语义质量仍需真实验收，评分不会自动成为线上发布证据。
    选择已完成实验，准备成对模型输出。
