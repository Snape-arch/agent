## 本轮自进化 Skill 复盘

实现遵循“外部技能制品进化”，不修改模型权重，也不允许运行时直接改生产 Skill：

```text
Reflection / 用户反馈 / 失败 Trace
  -> Candidate Skill Version
  -> Frozen Evaluation Suite
  -> Plan-only 或隔离执行
  -> Pass-rate + P95 Gate
  -> 人工 Promotion
  -> Active Skill
  -> 生产异常时 Rollback
```

该设计吸收了参考文献中的关键机制：

- Generative Agents：观察、记忆、反思、规划形成反馈循环。
- Voyager：可组合技能库、环境反馈、执行错误和自验证。
- MemGPT：分层外部记忆和显式读写控制。
- SkillOS：执行器与技能策展器分离，技能增删改以长期下游效用为评价。
- SkillEvolver：先部署候选给新代理验证，再审计过拟合、泄漏和“技能未被实际调用”。

当前实现是低风险工程版本，不包含在线 RL 自动写生产库。自动候选未来只能进入 Review
Inbox，发布权限必须与执行权限分离。

## 企业交付硬门槛

以下条件未全部满足前，不应对外宣称“企业级工业交付”：

1. MTT AIBOOK 上完成本地模型安装、离线启动、质量、P95 延迟、吞吐和资源报告。
2. Task 支持幂等、取消、重试、恢复、超时、补偿，进程重启后任务状态一致。
3. 接入真实用户、工作区、角色和授权，ACL 不再依赖调用方自报身份。
4. 敏感数据加密、OS Keyring、日志脱敏、数据保留和删除证明可验证。
5. 建立版本化数据库迁移、备份恢复、升级回退和故障诊断流程。
6. 高风险工具具备网络/文件/命令三类隔离、资源限额和完整审计。
7. 使用同一冻结任务集比较 DeepSeek 与本地模型，报告成功率、匹配准确率和 P95。
8. 前端可实时查看任务、确认高风险动作、追踪证据、回滚改进并导出审计记录。
