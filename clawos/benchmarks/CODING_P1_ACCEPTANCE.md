## 候选留出边界

- `CodingTaskExposure` 按冻结 Git 树和授权文件路径，以及非空源码的 Git blob 预留。普通策略运行在调用模型前记为开发暴露。离线候选将授权范围绑定到候选签名，拒绝与开发、其他候选或同一批中的其他任务重叠。同一候选同一任务重复仍按一个任务簇计算。进程中断后的预留保留。
- 旧报告可作为历史诊断。新留出预留还会核对已登记报告的冻结任务组及 Git 树内的写入范围，发现重叠或历史凭据不可核验时停止。原生候选回执重新验证预留才能进入既有门禁。没有预留的历史结果不用于新版发布。
- 留出结果保留原始回执和诊断，排除出故障候选提名和新反思卡。直接导入与已预留冻结范围重叠的普通对照报告会被拒绝。既有真实样本、影子、灰度和回滚条件继续生效。现有最低 30 个任务簇和质量／成本门槛保留。

## 回归结果

- 比较、策略和候选评估主回归 56/56，随后加入导入拦截及版本化诊断复验 6/6。最终定向覆盖改名源码、重复留出、无 usage、原生与导入来源以及伪造晋升指标。
- 结构化代码契约、并行 Git 工作区、同文件冲突、取消恢复及运行治理 22/22。自进化通用生命周期 8/8。模块结构检查通过。
- 旧真实模型报告 3 份、4 个变体可重新验摘要和读取原诊断。两份旧候选子报告仍按历史实验解释。没有把旧运行纳入本轮的模型结果或新版晋升证据。

当前隔离范围覆盖同一个证据库内的受管策略运行。源码经过修改、不同证据库、手工调优或外部先验仍需要独立审查。三道公开历史题不能作为私有留出任务。八个曾使用的本地模型端点均未响应，因此未运行本轮真实单／多代理对照，未评定模型收益或提升项目评分。
