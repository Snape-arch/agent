# 我的学习材料：五步工作流验收

日期：2026-09-14。入口 `/academy/materials`，学习工作室侧栏可访问。

## 已实现的范围

1. **材料导入**：PDF、DOCX、TXT、Markdown；20 MB 文件与 60 万正文字符上限；复用 `memoryos.document_ingestion.extract_text`。独立材料表与学习文件目录，内容摘要标记版本，同名新内容保留旧版；失败原因、重试和 OCR 复核提示可见。页码有来源才显示；无页码文本明确标为正文片段。
2. **可追溯导读**：原文与学习面板并列，按片段导航；模型给出解释、先修建议、阅读步骤和练习问题，引用须为可定位的连续原文。未调用模型时提供阅读步骤，不伪装为生成的论文结论。当前不是全书章节级总结。
3. **围绕材料教学**：目标与来源判断诊断、解释草稿、关联当前片段及最近诊断/评分的导师追问。草稿、材料、阅读位置和步骤可恢复。诊断目前针对来源核验，不是完整学科能力测验。
4. **真实项目验收**：用户编写至少两道有答案和一道无答案问题，配置字符检索参数；复用执行服务启动固定 Python 程序，真实 TaskRun/step 记录退出码、测试明细、输入/代码/报告摘要。导出可离线复现，改动产物后拒绝作为原运行导出；代码工作区显示同一任务并提供返回链接。执行成功与测试通过分开，不自动增加掌握度。
5. **语义评价**：共享模型分别按主评与复核提示评价机制、条件和反例；每项 0–2 分，要求学生原句和材料原句。矛盾、分歧、缺证据、结构异常、模型失败都不直接通过。结果保存题目、原文版本和量规版本。这是同一路由的两次判读，不是两名独立专家认证。

## 复现

离线专项：`python -m unittest discover -s clawos/tests -p test_academy_materials.py`。

隔离预览：`python clawos/scripts/learning_preview.py --models --port 18898 --session materials-acceptance`。省略 `--models` 不连接配置模型；`--session` 仅接受字母、数字、下划线或连字符，数据保存在忽略的 `output/learning-preview` 下。常规正式服务重启后加载新路由；本次未重启生产服务。

## 保留的边界

- 未宣称达到顶尖教育平台或 WPS 全功能。长教材跨章节导读、复杂公式表格学习、学科诊断和独立学生代码验收仍需进一步扩展。
- 默认 local-user 是单用户标识，不构成多租户鉴权。现阶段不对外部署。
- 不向模型自动发送整本教材；模型按钮会告知发送当前片段和相关学习输入。材料导出包含用户导入的解析正文，使用范围随原材料。
- 正式知识库、模型权重、tools、生产数据库与其他板块未提交改动不纳入本次提交。
