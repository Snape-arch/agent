# 研究方向订阅与发现日报

日期：2026-10-30。入口 `/academy/research`，由学习首页、教学工作区及论文阅读器进入。

## 已实现的链路

方向订阅 → 有界增量采集 → 持久身份去重 → 可解释多标签归类及人工修正 → 标题/摘要证据摘录 → 站内通知与北京时间发现日报。

- 订阅固定查询、来源和归类规则，可暂停、恢复、请求检查、删除。修改查询应建立新订阅，避免把旧查询的采集水位误用于新方向。每人最多 20 个，全站最多 100 个。
- 支持 Crossref 和 arXiv 自动采集；原 Crossref/OpenAlex/Semantic Scholar 手动检索保留。自动采集不经过六小时手动检索缓存。
- 默认 6 小时，支持 12/24/48/168 小时。应用运行期间每 15 秒调度到期任务；页面可见且未操作结果区时约每 30 秒刷新通知。关闭应用、休眠、断网期间不会采集；恢复后按持久窗口续采，没有操作系统外置常驻服务。
- 首轮回看 30 天，后续从上次完成水位向前重叠 7 天；每次最多处理两页，每页最多 50 条。未读完窗口保留分页位置并显示“积压”，不会用部分页冒充完整覆盖。
- Crossref 使用固定的 `from-index-date` / `until-index-date` 和 cursor；arXiv 使用固定首次投稿时间范围及分页，按投稿时间排序。arXiv 不保证发现窗口外旧论文的新修订；来源延迟、窗口之外的迟到记录及搜索召回率仍有边界，不宣称论文发布即发现或领域全量覆盖。
- DOI 规范化、去版本 arXiv ID、来源 ID 跨批次去重；标题回退要求年份和首位作者。冲突 DOI 不因同名合并。后到 DOI/arXiv 记录可归并此前分开的预印本/出版身份。全方向列表和日报按论文去重，同时保存各订阅归属。无法确认的同名文献不强行合并。
- 来源页、发现记录、日报条目和通知在同一 SQLite 事务中提交。任务租约与版本检查阻止过期进程、暂停/删除前的迟到结果写入。跨应用进程共享同一数据库的采集租约和至少 3.1 秒请求间隔；跨机器部署仍须自行协调公共 API 总速率。
- 失败保留安全异常类型/HTTP 状态，15 分钟后重试；不记录异常消息、请求头或凭据。失败从同一窗口重新分页并去重，水位不推进。原进程中断后租约 120 秒到期可接管。
- 归类使用配置关键词在标题、摘要、来源分类标签中的命中依据，明确标为待复核；可人工修正。它不是权威学科分类器。
- 总结首版为**精确的来源摘录**：摘要缺失时仅展示标题并说明限制。记录依据字段、字符区间、采集时间、快照 ID 与 SHA-256；快照载荷不随后来元数据更新而改写。没有隐式全文下载、模型调用或未经证据支持的效果结论。
- 日报是当日“发现”的清单，随新发现追加，不是当日“发表”的全集。已读通知不会被重复批次重新生成。删除订阅保留历史日报/来源快照；未提供个人研究历史彻底清除/存储回收功能。
- 服务使用现有会话身份，所有订阅、发现、日报、快照、通知按用户隔离；文档受邀账户只能访问自己的研究数据，不获得原全局检索、连接器或数据库权限。站内通知不会发送邮件/飞书消息。

## 实测与记录

专项覆盖：订阅到日报完整链路；跨批次/来源及跨订阅去重；后到稳定标识归并；同名冲突；分页/水位；重启后续采；旧租约/暂停/删除迟到拒绝；失败回放与事务回滚；跨用户隔离；冻结证据区间与哈希；空摘要/空结果；人工分类；共享采集锁与频率；实际应用路由/权限中间件；异步线程收尾。

公开 API 小样本：`scripts/research_watch_acceptance.py --live --output <独立输出目录>`。真实 Crossref 5 条、arXiv 5 条；每份捕获页在独立数据库实际入库后回放，第二次新增均为 0，摘录区间及快照哈希一致。真实返回均仍有后续页，**没有完整采完来源窗口**。回放夹具中的 `complete=true` 仅表示该捕获页作为本地回放集合已结束，不能当作真实来源的覆盖证明。

首轮 Crossref 返回 HTTP 400，实测确认索引时间参数不接受末尾 `Z`；修正为 UTC 无后缀格式后两来源通过，增加参数回归。初始失败证据保留在 `output/research-watch-live-20261030/live-result.json`，成功证据在 `output/research-watch-live-20261030-b/`。输出不提交。

浏览器在独立端口 18926、独立数据库和明确标注的人工夹具上验证：新建订阅、后台采集、两来源同一论文去重、归类依据、人工修正、日报打开及未读从 1 到 0。米白页面在约 845×738 视口检查；截图 `output/playwright/research-watch/daily-digest.png`。这是桌面浏览器人工样例验收，不代表移动设备、屏幕阅读器、多天负载或真实科研结论验收。

受限终端首次运行的 SQLite 临时目录不可写、异步 API 测试停滞，因此未计通过；改为获准主机执行、工作区内独立临时目录后复验。既有协作交付测试最初因缺少 `clawos/tests` 导入路径失败，修正测试环境后重新运行；不修改既有业务源码掩盖失败。

最终相关回归 **53/53**，0 失败/错误，20.636 秒（研究订阅 27 项）；此前含既有协作交付的组合 **66/66**，331.333 秒通过。66 项组合早于最后共享采集锁改动，最终锁逻辑由上述 53 项覆盖。JS 语法及 diff 检查通过。未复用旧 1102 项或协作长测作为新功能的验收。提交状态见本次交接记录。

## 可复现命令

Windows 使用已验证的应用 Python，设置 `PYTHONPATH=clawos;clawos/tests`、`CLAWOS_SKIP_LOCAL_ENV=1`，`TEMP/TMP` 指向新建的工作区临时目录后执行：

```text
python -m unittest test_research_watch test_paper_intelligence test_collaboration_workbench -q
node --check clawos/static/assets/research-watch.js
python clawos/scripts/research_watch_acceptance.py --live --output clawos/output/research-watch-live-<new-run>
python clawos/scripts/research_watch_acceptance.py --preview-port <unused-local-port> --output clawos/output/research-watch-ui-<new-run>
```

预览限定 loopback、独立 DB 与人工夹具，拒绝复用已有预览 DB；不启动或重启生产。正常应用重新启动后才加载新路由及后台采集，不修改运行中的冻结协作压测快照。
