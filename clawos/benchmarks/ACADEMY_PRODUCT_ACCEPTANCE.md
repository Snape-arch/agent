# 教育、阅读与学习文档验收（2026-10-02）

本轮面向 Windows 本地个人学习产品。源码、自动化验证和可复现脚本交付；真实教师质量、多日运行与多人协作不能用开发样例代替。

## 实际改动

- 教师校准：人工署名、日期、复核声明和原文定位；至少 3 个量尺示例、6 个独立验收样本，各自覆盖 concept/reasoning/transfer 的 0/1/2 分。示例与验收答案不可重复。两个教学角色分别评分，保存一致率、平均绝对误差、混淆矩阵和错误通过数。验收条件为一致率至少 85%、平均误差不超过 0.25、错误通过为 0。材料版本、量尺、路由配置或 rubric 改变后旧验收失效。校准失败时全分练习也需要复核。
- 跨章教学：选择 2–4 章，提出联系、冲突和迁移三类问题；每章必须提供可定位原句及其作用。学生提交三项综合论证和覆盖全部章节的证据解释，保存后等待人工复核。研讨不会自动折算学科掌握度。
- 文献阅读：铺满应用窗口、折叠目录/笔记、真实 PDF 页码与目录、缩放/适合宽度、可选择文字层、逐页批注、来源版本隔离、页码链接恢复和阅读检查点。原文按页渲染，批注与该页几何坐标绑定；非 PDF 正文保留完整分块并分页加载，不再只展示截断预览。检查点重新读取当前资料，旧版本引用必须重新核对。
- 学习文档：替换旧的“生成结构化草稿”页面，加入正文、标题、引用、提示、列表、待办、代码、表格、图片、可编辑笔迹和分隔线。支持行内格式、代码缩进/复制、表格行列操作、块移动/复制/删除、学习模板、目录、专注/预览、Markdown/JSON 导入导出。阅读笔记可以带文献及页码转为独立文档；AI 导写建议经用户确认后插入。
- 保存与恢复：SQLite 版本比较更新，阻止并发页面覆盖；自动保存、设备草稿、撤销重做、最近 50 个持久化版本、冲突另存副本。导入先通过服务端结构验证，正文不作为可信 HTML 执行，代码块仅用于记录。
- 完整资料备份：SQLite 快照、登记的教材/文献原文件及现存运行产物，逐文件摘要与大小校验；缺少原资料拒绝完整备份，缺少历史产物明确登记并标记 degraded。恢复只允许新隔离目录，重新绑定文件 URI 和数据库 JSON 中的精确路径，保留原始文件字节和历史说明文字，清除旧向量状态后从规范记录重建。
- 工具子进程回归现使用独立数据库和产物目录。自演化测试保留真实质量、因果证据和失败门禁，只允许机器竞争导致的实测延迟退化形成正确拒绝；生产门禁未放宽。自定义产物目录下的 Obsidian 相对路径也已修复。

node --test clawos/tests/academy_labs.test.cjs clawos/tests/chat_content.test.cjs

1. 教师需填写真实人工量尺和保留样本。当前“尚无教师标注”是正确产品状态；署名来自提交者声明，无法认证教师身份。两个角色共用一个路由，不代表两个独立专家模型。

5. 文档是本地块编辑产品，没有飞书式多人实时协同、评论/@、权限认证、跨设备同步、复杂布局或完整 DOCX/PDF 导出。绘图编辑数据保存在 JSON，Markdown 导出以说明占位，不保留可编辑笔迹。
