# 跨仓库编码盲测

首批使用两个固定版本的 Python 上游代码切片，各四道题。部分任务在上游代码中注入回归，部分任务要求原有实现增加新契约。题目与独立测试由本轮编写，参考解只用于预检。上游公开源码可能存在于模型训练数据中。本批测量的是模型对未公开任务和后置检查的表现，范围限于选定的模块。 [CPython 固定提交](https://github.com/python/cpython/commit/4a5632fbf9bf59477c540e3f53fa7cdbeea3e3f5) [boltons 固定提交](https://github.com/mahmoud/boltons/commit/d31d821d56c8f7756af9c30a864077f2e5855321)

每题冻结写入范围、目标、公开命令和独立复验命令。真实模型只接收隔离工作区内的授权源码、任务目标和公开测试反馈。后置命令在共同复验工作区运行，不回传给模型。参考解、错误解、独立测试和原始回执均留在忽略目录。

预检对每题运行三个变体。原始版应同时失败，参考版应同时通过，只通过公开测试的错误版必须被后置检查拒绝。每个退出结果均核对真实 AppContainer、令牌、Git 控制指针封存和权限回收。失败必须来自明确的 Python 断言。两模式共用原比较服务的模型、预算和证据核验。

运行器接收 `clawos/output` 内的私有题包。题包的 `tasks.json` 声明 `schema` 为 `clawos.crossrepo-blind.v1`，逐题提供 `id`、固定上游 `upstream`、`paths` 和 `objective`。每题目录包含 `baseline`、`reference`、`public_only` 三份带许可证的同结构源码，以及 `public.py` 和 `post.py`。运行器校验工作区封存后才接收隐藏终端密钥。

```powershell
.\clawos\.venv\Scripts\python.exe clawos/scripts/run_coding_crossrepo.py --pack <私有题包路径>
.\clawos\.venv\Scripts\python.exe clawos/scripts/run_coding_crossrepo.py --run <通过预检的输出目录> --seal-digest <预检摘要>
```

首轮预检 `output/xr/14a1d6e1` 未用于模型调用。Python 启动引入了系统自带的 `fnmatch`，使跨文件题的参考解失败。识别断言的代码也漏判了无消息的 `AssertionError`，最后写封存报告时重复创建了预检目录。保留首轮诊断，修正导入绑定和运行器后重新预检。

第二轮 `output/xr/9eaa90c5` 暴露了测试生成器的拼接换行问题，并因实现指纹变化拒绝封存。第三轮 `output/xr/3cd47b15` 确认跨文件题改用冻结模块后通过对照，但有一项沙箱命令退出 `3221225781`，另有一项故意错误解的有效输入拒绝需要转换为显式断言。第四版在独立目录的快速对照先验证 48/48 预期退出，再串行运行严格预检。前述诊断均发生在模型调用前。

第四轮 `output/xr/51563f3b` 的 8 道题全部通过严格预检，48 次命令退出符合预期。12 份上游文件（含两份许可证）的 Git blob 逐一与固定提交一致。封存摘要为 `baeb19f719431321ce0ac24cbdc8241940a897673107f565313f46c072ed8f8a`，包含 22 个实现指纹。封存拒绝路径越界、脏快照和替换后置测试的两项回归通过，原比较服务 16 项回归通过。
