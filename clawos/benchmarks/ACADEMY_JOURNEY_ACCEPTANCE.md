# 教育产品与编排链路验收（2026-10-01）

本轮围绕已存在的教育领域完成升级，没有引入第二套模型、数据库或 agent 框架。

## 已交付的产品体验

- 学习工作室首页展示当前学习者最近的材料，可直接回到材料的今日计划。
- 材料首页按 20/40/60 分钟预算安排任务，优先到期复习和薄弱章节；任务指向实际章节。待复核内容单独统计。
- 章节回答通过后，次日进入复习。先提交三题闭卷回答，再揭示来源与评价要点。用户自评决定 1/3/7/14/30 天间隔，忘记时重置到一天；自评不产生掌握度证据。
- 闭卷回答揭示后不能覆盖；重复提交相同回答和相同自评可安全重试。未完成的复习可恢复，浏览器草稿和预算经过刷新验证。
- 复习绑定材料版本、诊断题版本及当前评阅版本。原文、题目、提交或评阅变化后，不继承旧通过状态，也不接受旧复习记录。
- 学习档案导出 JSON，包含当前材料版本、题目、回答、评阅、模型调用角色轨迹、项目事件及复习历史。只查询当前材料与学习者，不包含其他材料、权重、凭据或数据库。
- 教学模型操作记录共享 RunRecord：每次调用的角色、请求/响应摘要、耗时、引用验证状态及对应学习事件。提供方异常、非法引用或无效模型输出会形成失败记录，不会留下成功成绩。双教师采用同一共享模型路由的不同提示；不能宣称不同模型或专家之间的独立认证。

## 修复的编排与数据问题

- 普通角色失败原来可能被整体判为 passed；现在失败或阻塞明确阻止释放，依赖它的角色不会调用模型或工具。
- 提供方初始化异常保留已完成的独立角色和检查点。发现循环依赖时，在执行前拒绝。
- 返工重跑执行者受影响的下游角色，确保中间产物和评审读取新版本；同批已经执行的独立角色不会因其他硬门禁失败而丢失记录。
- 恢复任务要求目标、角色策略和共享证据摘要一致，只重试失败分支及失效依赖。没有开启审查的检查点不再误启审查。旧检查点缺少证据摘要时需要新建运行，原文件保留。
- 同分数的固定角色审查不再共用运行 ID。持久化状态与最终返工工作流一致，初次门禁仍保留供审计。缺少门禁证据的工作流拒绝通过。
- 提供方报告 token 使用超预算时，结果标记预算耗尽。此门槛在调用返回后执行，不能保证并行请求绝不产生超额费用。
- 只读数据库体检除 SQLite 完整性外，还检查文档块、教育事件、复习和知识来源的逻辑孤立记录，以及向量同步队列积压/错误。缺少原始文件或孤立记录判失败，同步积压判 degraded；不把这些问题藏在 SQLite integrity=ok 后。

剩余问题按优先级：

1. **P1：评测校准**。双提示评阅和个人复习自评不能证明实际掌握，需要教师标注题库、真实学习者、多样错误样本及一致性测量。
2. **P1：课程深度**。章节仍按提取标题/片段划分，尚未建立可靠的整本教材先修关系、公式/表格教学与跨章迁移评估。
3. **P1：长期运行与恢复**。需要多日运行、断电/进程崩溃演练、并发编辑冲突和任务时限的实测。检查点目前属于受信任本地文件，不是签名防篡改存储。
4. **P1：完整备份与知识检索**。SQLite 健康与 outbox 清空不证明向量结果准确。仍需资料文件/向量资产联合恢复，以及独立真实检索质量、延迟、引用正确率评估。
5. **P2：可商用边界**。当前 local-user 是本地单用户约定，没有多租户鉴权、教师复核协作后台或跨设备同步；复习日期只在应用内展示，没有后台通知调度。
6. **P2：实践验证**。教材 RAG 项目执行内置固定程序，开放式探究只保存学生自述；任意学生代码仍需成熟沙箱和独立隐藏测试后才能接入。
