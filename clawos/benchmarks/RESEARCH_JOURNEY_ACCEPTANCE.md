# 研究、可视化教学与原Agent反馈链路验收（2026-11-05）

本轮把固定RAG样板接成同一份研究学习计划，入口为 `/academy/vision/#journey`。默认入口仍为可视化课堂，统一13视图、保留18插件与暖米白/森林绿。它不代表所有领域的任意文献都已自动生成课程。

## 一份原件贯通哪些工作

现有订阅／跨批去重／方向分类／站内日报 → 原研究case/hash中的10篇固定版本PDF（169页）与独立作者摘要 → 证据综述和概念先修候选 → 六单元约55分钟建议路径 → Vision机制课堂与同语料BM25范围实验 → 原论文阅读器、知识库与教材学习／教师校准 → 原文献主张评审 → 有门禁的原Agent诊断。

文献卡支持固定原件展开、下载、资料夹／标签／阅读状态／笔记CAS保存；PDF始终核对捕获SHA，不按同名自动替换。显式导入复用 `ingest_file`、知识索引刷新和 `AcademyMaterials.upload`，DPR实际产生55知识片段，材料摘要与原PDF一致。哈希去重、导入租约及部分失败状态保留，不宣称文件系统与多个解析器是一个原子事务。课程解释只记录本人输入，不自动认证掌握或教学收益。

原生PDF iframe在IAB实测黑屏，因此统一复用原 `PdfPageRenderer` 的字节入口，显示实际原页图像／提取文字、分页、原件SHA及页数。原阅读器使用既有 `document`、`reader=window`、`notes=collapsed` 入口，支持批注和笔记；跨页保留研究case返回栏。修复页码True与1命中同一缓存键的问题，访问缓存前先验整数。原书架和校准页接同一材料ID，未创建新的教师工作台或假标注。

## 模型问答与自进化的边界

新增30道助手拟定候选（事实、跨论文比较、证据不足各10），不是独立金标准或未知测试集。每题固定问题／查询／候选数，对摘要和全文分别最多调用一次已配置本地模型，90秒／次、1500输出tokens，温度0、无工具、无外部回退、不启动权重。保留提供方声明身份摘要、提示／schema／响应摘要、usage、耗时、完整结束状态、6份执行／守卫源码摘要及冻结题库。身份变化、源码变化、过期租约和取消不能晚发布；原综述与新问答队列共用数据库互斥。证据为空不调用模型，不补造回答。当前列表显示最近20份回执，更多记录仍保留在库且可用已有ID读取／导出，批量评测管理尚待进一步完善。

严格JSON、已召回引用ID／连续原句、部分数值及主张边界守卫仅是机械检查；通过仍需语义复核。回执复用原AI证据封套与原文献评审台，重复送评返回同一冻结轮。补齐旧综述所需覆盖统计／暂扣字段，正确显示全文来源与RAG回执类型。真实独立评审仍需两名评审者与一名仲裁；本轮没有假填教师或独立身份。

ClawOS Agent继续负责身份、执行、模型调用、共享存储和策略治理；Vision是可视化与实验工具，教育是垂直应用，不另起第二套自进化Agent。只有明确提交的实际格式或引用契约失败可写入原 `MemoryStore` Reflection，按case/hash/问题/故障去重；不创建improvement、候选、run、奖励或已发布策略。学生自述、数值／语义待评、网络故障不冒充策略升级证据，原回放／回归／影子／灰度门禁保留。

实际跨页验收发现原Console错误请求 `/api/reflection/cards` 并吞错显示暂无记录；已修到真实 `/api/reflection/list`，读取失败现在显示明确错误。隔离浏览器经显式提交实际看到原Console诊断卡1条、改进建议0条、Vision worker未启动。该演示使用清楚标识的合成回复，实际LLM调用为0，不能视为真实模型质量或策略收益。
