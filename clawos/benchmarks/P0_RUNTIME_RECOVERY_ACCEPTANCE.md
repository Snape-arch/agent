## 交付与边界

- `/api/runtime/release` 和 `/health.release` 返回实例 ID、启动提交、启动/当前源码摘要及变化文件。覆盖顶层 Python，以及 api/services/memoryos/providers/reflection/security/mtclaw/static/skills/scripts 的明确源码后缀；不读取配置、`.env`、数据库、tools 或模型权重。启动文件快照不等于所有延迟导入模块的实际加载证明，也不覆盖外部依赖或工具定义版本。
- `/health.core_ready` 要求数据库可访问、工作区服务初始化、启动源码未漂移、向量初始化/一致且未降级。`status: ok` 保留为存活信息，模型实际可达性单独探测。启动器使用 `--require-ready`，拒绝旧健康格式、漂移、空向量状态和降级。
- 本地模式跳过项目 `.env`，先检查本地检索依赖；`CLAWOS_PYTHON` 支持明确选择已准备好的解释器。隔离回归和预览导入同样跳过项目 `.env`。这不承诺清除人工继承的所有环境变量；本轮生命周期 QA 使用环境白名单且飞书 live 关闭。
- 恢复包纳入 `artifact_delivery/index.json` 注册的现存文件，以及任务 `checkpoint_path` / `latest_checkpoint.uri`。恢复后路径重绑定，下载保留原 opaque ID；文件清单须绑定数据库/注册表原始引用和已知摘要，拒绝将另一份有效文件偷换给教材。
- 缺失原文/教材/检查点拒绝宣告完整备份；缺失历史产物明确列入降级清单。旧 v1 包没有新字段时仍按旧范围验证，不补造旧下载/检查点证据。
- SQLite 是已提交快照，文件与注册表做稳定性复核；它们不是跨进程分布式原子切面。未注册文件、任意 Git 工作树、进程租约、外部资源和权重不包含。复制检查点不代表任意执行任务可续跑。隔离恢复不替换日常数据库。
