# RAG 入门示范课与试学方案

从学院首页的「开始 RAG 入门示范课」进入，也可从站内通知打开日报，在 DPR `2004.04906v3` 的发现卡进入。已有研究计划可从固定全文综述直接打开对应课件。首次使用需要在 RAG 文献实践准备公开资料，之后可以复用本机捕获。

## 学生完成什么

课程建议用时约 15 分钟。先答三道前测，读 DPR 作者摘要并打开固定 PDF 的第 1 页。写下预测后运行两组检索，对照「包含旧版」与「只检索现行版」的首条片段和匹配分。借用期限一题用于区分相似度和适用版本，停车费用一题用于识别缺失证据。学生保存观察，再做三道换情境的后测和一道书面迁移题。

DPR 论文用于解释稠密表示。对照实验使用现有 Vision 的字符二元组检索，在六份人工短文上执行，界面聚焦其中两道题。唯一改动项是版本过滤。记录保留两个条件、召回片段、匹配分、试题版本、原件摘要和实验结果摘要。它可在本机恢复，不需要启用模型或另启 Vision worker。

每份计划在本机保留一份进行中的练习。完成后可以开始下一份，旧记录可用原页面地址恢复。两套前后测按开课顺序交替交换，整节完成后才显示解析。新练习需要固定 PDF 原件通过摘要校验。记录会保存在本机，教师复核包只包含迁移题、作答和量尺。当前操作使用本机所有者权限，没有独立的学生账号或教师判分认证。

## 教师先校准，再收集数据

1. 独立检查六道自测题的答案、用词与难度。按同一概念逐对比较 A/B 情境，记录题干理解分歧与可能的答案提示。下列迁移锚点是拟定的讨论样例。
2. 请两名教师各自评三个锚点，逐维打 0–2 分并圈出学生原句。讨论差异后冻结量尺和材料版本。开始试学后，如需改题或改量尺，另起一批记录。
3. 先做 8–12 名初学者的可用性试学。给每位参与者独立练习编号，第一次作答时由观察者记录卡点和求助情况。真实参与名单和同意记录与应用导出分开，提交给教师前检查自由文本是否含个人信息。按报名、开始、完课和有效配对分别报告人数，保留退出原因。
4. 教师只看复核包，先独立评迁移题，再对照分歧和原句。课程观察可预设 **80% 无指导完课、迁移总分至少 4/6 且版本和证据两维均非零** 为本轮改进门槛。报告每个分母、前后测个体变化、A/B 顺序、各维一致率和独立复核结果。
5. 要估计学习效果，再用事先约定的等时对照、随机分配和延迟迁移题开展独立验证。当前三题自测尚未证明等难，短课流程测试及小样本前后分数只支持改课判断。

| 拟定锚点 | 版本与适用性 | 证据与结论 | 下一步核查 |
|---|---:|---:|---:|
| “按旧通知收 50 元。” | 0 | 0 | 0 |
| “旧通知已经作废，费用不确定，我再确认一下。” | 1 | 1 | 1 |
| “50 元来自已废止通知。现行通知只支持提前预约，押金未知。我会查当前面向校外访客的收费条款，或向实验室确认生效日期和适用对象。” | 2 | 2 | 2 |

用「下载完整学习记录」保存前后测、实验和来源回执，用「下载教师复核包」发给独立评分者。评分表可按 `练习编号 / 评分者代号 / 版本分 / 证据分 / 核查分 / 每维原句 / 分歧` 记录。课堂数据没有写入掌握度或 Agent 策略奖励。真人教师校准和学生试学目前待开展。
